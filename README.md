# 🏕️ Git Bootcamp Project

A beginner repository created during my first hands-on Git & GitHub bootcamp session to learn foundational version control workflows.

---

##  Overview

This project marks my first hands-on interaction with Git and GitHub. It serves as a practical practice space to understand repository management, track file changes, and explore web development fundamentals using basic HTML.

---

##  Key Learnings

- **Git Basics:** Initializing repositories, tracking files, staging changes (`git add`), and writing commit messages (`git commit`).
- **Remote Repositories:** Connecting local projects to [GitHub](https://github.com/swathipoojary11/git-camp), pushing commits (`git push`), and syncing branches.
- **GitHub Workflow:** Creating and editing files directly via the GitHub web interface, managing branches (`main`), and documenting projects with Markdown.
